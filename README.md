SAFE CYBER BANK - client-side demo

Open `index.html` in a browser to run the app locally.

Pre-seeded users:
- saran / saran2026 (client)
- naveen / naveen2026 (client)
- prasanna / prasanna2026 (client)
- administrator / admin2026 (admin)

Notes:
- Initial balance for clients is $1000 and transactions are empty.
- Data is stored in browser `localStorage` under key `scb_state_v1`.
- Administrator can use "Add Credit" to credit any user's balance.
- Clients can use "Send Money" to transfer to other clients.

To reset data, clear site Local Storage for the page or run in an incognito window.
